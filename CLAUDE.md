# CCA-F study repo — working rules for Claude

This repo is study material for the **Claude Certified Architect – Foundations** exam. See [00-index.md](00-index.md) for the domain map and [90-cross-cutting-reflexes.md](90-cross-cutting-reflexes.md) for exam tactics. The rules below govern how you *work in* this repo; don't restate the index here.

## Answering me
- Be concise: lead with the answer, cut preamble and repetition, don't restate the question or re-explain the same point in different words. Expand only when I ask.

## Verify before asserting
- For any **version-gated / deprecated / removed / added-in-vX / default-changed** claim: **fetch the official doc first** — never answer from memory or a web-search snippet. A snippet or a GitHub-issue *title* is a lead, not a citation.
- Official sources only: `platform.claude.com/docs`, `code.claude.com/docs`, `anthropic.com`, `claude.com`. Treat study blogs as unofficial and verify their rationale against docs.

## Routing lessons (by kind — not to auto-memory)
- **Durable domain concept** → the matching domain file (`01`–`05`).
- **A missed/blown question** → [99-mistakes-log.md](99-mistakes-log.md), *before moving on*. Include: scenario · what was picked · correct answer · one-sentence why.
- **Domain-agnostic judgment / distractor pattern / tiebreaker** → [90-cross-cutting-reflexes.md](90-cross-cutting-reflexes.md).

## Writing entries
- Format: **Concept → Rule → Trap → (source link)**.
- Cross-link with relative links; keep [00-index.md](00-index.md) the hub.
- Avoid verbosity and duplication — tighten existing entries rather than appending near-duplicates.
